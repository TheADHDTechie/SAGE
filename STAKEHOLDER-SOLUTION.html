Stakeholder solution brief

SAL WhatsApp Support Assistant

Trusted, bilingual answers from SAL's Teacher Librarian Guide through the channel communities and staff already use.

W
WhatsApp-first Users ask questions by text or voice memo and receive concise, cited answers.
Aa
English + Kiswahili The assistant understands both languages and responds in the user's language.
58
Manual grounded Answers use 58 reviewed knowledge chunks from the 44-page SAL guide.

Solution architecture

A lightweight API coordinates WhatsApp, SAL's local knowledge and approved Azure AI services.

GroundedAnswers use the approved SAL guide and include page citations.
AccessibleSupports text, voice, English, Kiswahili and mixed-language questions.
Human backedUnsupported and sensitive enquiries move directly to SAL staff.
Lean startNo vector database or agent framework is needed for the first release.
